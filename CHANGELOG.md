# Changelog

## 1.0.0 — 2026-09-13

Stable native community release with completed Embassy and Sovereign modes.

- Embassy publication controls, isolated signing gateway, origin-bound native specialist
  contexts, bounded three-tool MCP service, one-use approvals and drain/withdrawal handling.
- Sovereign deployment using published nano-init/sam-box, credential-verified TCP-only named
  egress, isolated native UI ingress, expiry/restart supervision and state-preserving rollback.
- Strict runtime certification bound to the host, source, binaries, plugin code and approval
  UI, including real native guest startup/model execution and positive/negative network checks.
- Real enrolled-mesh and native model acceptance against released and current-main SAM,
  with real governed specialist completion, spoof/session/replay rejection and cleanup.
- Native Alpine publication snapshots, bounded specialist schema, non-overlapping key mounts,
  published CONNECT wire support and certified synthetic dual-stack DNS handling.
- Coordinated SQLite WAL initialization and revalidated stale sidecar observations to keep
  concurrent audit writes reliable without retrying transactions.
- Updated runbooks, compatibility evidence and Plugin Index submission. Explorer remains
  the default; existing persisted schema identifiers remain compatible.

Sovereign requires a passing Linux host certification; the tested Docker Desktop LinuxKit
kernel is unsupported. Embassy v1 specialists have only the response tool. Raw MCP and
universal structured function-tool provider compatibility are not part of this release.

## 1.0.0-alpha.1 — 2026-09-11

First public community preview of SAM Mesh for Agent Zero.

- Native plugin installation, scoped settings, Open action, right-canvas Observatory,
  nine tools and prompts, provider registration, and lifecycle hooks.
- Explorer defaults, exact-destination approvals, encrypted temporary decisions,
  quotas, redacted audit, and an offline emergency disconnect.
- Connected-peer TCP and descriptor-pinned UDS transports, bounded schema validation,
  and an unknown-risk approval floor when remote annotations are absent.
- Native mesh inference and protected named requests with no extra client retries.
- Original logo, Plugin Index thumbnail, MIT license, reproducible verification,
  and pinned/current-upstream framework CI.

Embassy publication, Sovereign startup, Raw MCP, and automatic MCP registration remain
unavailable. Live enrolled-mesh and real-model acceptance are pending. See the
[release assessment](docs/release-readiness.md) before evaluating enabled outbound features.
