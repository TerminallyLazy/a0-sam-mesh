# SAM Mesh logo

The six connected nodes and flowing paths represent connected agents and deliberate
passage between peers. The mark is original project artwork generated with the built-in
OpenAI image generation tool on 2026-09-11, then refined with the same tool. It is not an
official Agent Zero or Google mark and implies no endorsement.

- `webui/logo.png`: full 1254 × 1254 pixel artwork, used in the README and native settings.
- `webui/thumbnail.webp`: 384 × 384 pixel listing derivative, 8,108 bytes, within the
  Plugin Index's square-image and 20 KB limit. Downscaled with Lanczos and encoded as WebP.

The artwork is distributed with this project's MIT license. Keep the original proportions
and sufficient surrounding space; do not stretch the mark or add lettering inside it.

Style/medium: crisp flat graphic design with precise geometry and optical balance; choose a restrained high-contrast palette suitable for both a dark developer UI and a small thumbnail. Clean solid dark background.

Constraints: no letters or words, no robot head, no brain, no shield, no lock, no circuitry clutter, no gradients, no glow, no textures, no shadows, no existing company logos, no watermark.
